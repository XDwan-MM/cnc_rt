## 测试顺序与记录表

由熟悉台架的同事操作，先使用已审核的原版测试程序及匹配的参数。
先在无切削负载、有充分行程余量的条件下低速验证，再决定是否进入受载测试。
不临时猜测攻丝/回退指令，不强制夹紧、急停、驱动健康或 FIN 信号。
回退按现场既有操作流程触发，不以断电或急停替代正常回退入口。

| 顺序 | 场景 | 验收重点 | 结果/日志时间 |
|---|---|---|---|
| 1 | 启动与故障检查 | 四轴故障码、状态字、使能；正常条件下 F0.6=1 | |
| 2 | 若启动已有轴故障，按复位 | 对应轴报警可见；清错后才恢复健康；不清除则停止后续运动测试 | |
| 3 | 单独 M19、重复 M19 | 实际定向后才完成，释放后能继续操作，无旧高电平假完成 | |
| 4 | M29 后 M05、M03 | 握手不超时，退出后正常停止/起转，无残留定向动作 | |
| 5 | 单段刚性攻丝完整进退 | 主轴/Z 方向及同步符合程序螺距，换向和返回位置正确 | |
| 6 | 连续多孔/多段攻丝 | 段间无额外整圈或不足一圈的空转，角度/位置不逐段累积偏差 | |
| 7 | 下行过程按既有流程触发攻丝回退 | 主轴反转与 Z 退出同步，无先独转再走轴，回退终点符合既有设计 | |
| 8 | 换向附近及上行阶段的允许回退入口 | 仅测试原流程允许的入口；不重复反转、不超出行程、不挂起 | |
| 9 | 回退完成后再攻丝，再 M05/M03/M19 | 状态清理完整，无旧目标、旧握手或旧模式残留 | |
